# 🚀 Computer Class Website

A modern, responsive, and professional computer courses website built with plain HTML, CSS, and JavaScript. The design focuses on a clean learning experience, updated course categories, and strong UI/UX for students exploring tech skills.

## ✨ Highlights

- Premium and attractive landing page design
- Responsive layout for mobile, tablet, and desktop
- Searchable and filterable course explorer
- Professional enrollment form with dynamic fee selection
- Modern course detail pages for student learning
- Updated trending tech tracks such as AI, React JS, Cyber Security, and Data Analytics

## 🧠 Tech Stack

- HTML5
- CSS3
- JavaScript
- Static multi-page website architecture

## 📚 Course Categories

- Web Development
- Programming
- Database
- Design
- Office Productivity
- AI & ChatGPT
- Data Analytics
- Cyber Security

## ▶️ Run Locally

1. Open the project folder.
2. Launch `index.html` in your browser.
3. Or use a lightweight local server if you want a smoother preview.

## 🎯 Project Goal

This website is designed to help learners discover practical computer skills in a clear, modern, and engaging way. It acts as a professional course brochure and enrollment platform for education-focused digital learning.
